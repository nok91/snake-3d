# snake-3d

A low-poly 3D Snake game, playable in the browser on mobile and desktop.

Built by the Paperclip AI team. The CTO sets up the Next.js app as the first task.

## Deployment

Hosted on Netlify. `netlify.toml` holds the build settings; don't rely on the Netlify UI settings.
Pull requests get Deploy Previews, and merges to `main` deploy the live site.
